# Звіт ЛР1 ExpoGuard

Бурлій Андрій Євгенійович, група ІО-32.

[PDF-звіт](SP_Lab01_Burlii_IO-32.pdf) оформлено через Docex за зразком ЛР1 Омельченка. Він містить титульну сторінку, процес роботи, п'ять справжніх скриншотів, вимоги ExpoGuard, висновки та джерела.

Історія підготовки:

- [48ff001](https://github.com/AndriiBurlii/ExpoGuard/commit/48ff001): база STM32 HAL, Docker, UART і LED.
- [b95ce2e](https://github.com/AndriiBurlii/ExpoGuard/commit/b95ce2e): терміни та PRD ExpoGuard.
- [e7af610](https://github.com/AndriiBurlii/ExpoGuard/commit/e7af610): план лабораторних робіт, компонентів і тестів.
- [90102c2](https://github.com/AndriiBurlii/ExpoGuard/commit/90102c2): логи двох чистих збірок на Mac та гайд передачі в Ubuntu.

[Фактичні перевірки та їхні межі](validation/README.md)

П'ять скриншотів включено до PDF-звіту.
