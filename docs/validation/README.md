# Фактична перевірка ЛР1

Чисті збірки з логами виконано 03.10.2026 на macOS Darwin 27.0.0 arm64, Docker Desktop context `desktop-linux`, engine Linux arm64. Сирі версії та UTC час у [environment.txt](environment.txt); образ і ARM GCC у [toolchain.txt](toolchain.txt). 04.10.2026 користувач надав п'ять скриншотів ExpoGuard та відеозапис демонстрації.

## Результати

| Перевірка | Факт |
|---|---|
| B-01 | `make clean`, `make build IMAGE=expoguard-lr1-build:local` завершилися з exit 0, ELF/HEX/BIN створено |
| B-02 | Друге `make clean` видалило build; повторна збірка exit 0; `cmp` маніфестів SHA256 exit 0 |
| Компілятор | ARM GCC 10.3.1, ціль Cortex-M0+, образ `expoguard-lr1-build:local` linux/arm64 |
| Розмір | text 13464, data 120, bss 1808 байт за `arm-none-eabi-size`; перевищення linker memory не було |
| Попередження | У двох логах не знайдено рядків `warning:` або `error:` компілятора |
| Базові файли | 99 файлів шаблона, крім адаптованого README, побайтно ідентичні; [template.sha256](template.sha256) |
| UART/LED код | USART2 PA2/PA3 AF1 115200 8N1, PA5 toggle та HAL_Delay 1000 підтверджено по джерелах |
| B-03 Ubuntu | На [початку збирання у звіті](../SP_Lab01_Burlii_IO-32.pdf#page=3) та [завершенні у звіті](../SP_Lab01_Burlii_IO-32.pdf#page=4) збирання видно `make build`, Docker-образ, ELF/HEX/BIN і повернення в командний рядок. Повторні чисті збірки та SHA256 в Ubuntu цими знімками не підтверджені |
| B-04/B-05 Wokwi | [Перший знімок у звіті](../SP_Lab01_Burlii_IO-32.pdf#page=6) показує `STM32C031C6 ready` і `tick 0`..`tick 2`; [наступний у звіті](../SP_Lab01_Burlii_IO-32.pdf#page=7) містить `tick 0`..`tick 7` та інший стан LED. Код задає затримку 1000 мс; точний період за статичними знімками не вимірювався |
| Ліцензія | Наявність ліцензії підтвердив користувач; надані знімки показують запущену симуляцію. Trial не активовано |
| Сенсори | Не реалізовані, не тестувалися, схема та .ioc не змінювалися |

Повні логи: [build-1.log](build-1.log), [build-2.log](build-2.log). Маніфести: [build-1.sha256](build-1.sha256), [build-2.sha256](build-2.sha256).

Рівність підтверджена для цього шляху монтування `/workspace` і цього образа. Dockerfile використовує неприкріплені пакети; майбутня перебудова образа або інша архітектура може дати інші файли. ELF містить debug info, тому шлях також впливає на порівняння. Загальну відтворюваність між ноутбуками ще не доведено.

## Матеріали та межі перевірки

[PDF-звіт](../SP_Lab01_Burlii_IO-32.pdf) містить результати збирання, UART/LED, PRD, компоненти ЛР2 та джерела. [Скриншот PRD у звіті](../SP_Lab01_Burlii_IO-32.pdf#page=10) показує ExpoGuard у VS Code. Відео та його SRT/PDF-розшифровка збережені поряд із редагованим звітом у Reports і не входять до Git.

Залишаються окремими пунктами методички: скриншоти CubeMX, п'ять фактичних складнощів із причинами та рішеннями, повні datasheet фізичних аналогів компонентів. Технічні рішення зі звіту не підміняють п'ять інцидентів. Детальний перелік: [lab-plan.md](../lab-plan.md).
